# Bossa

A native macOS menu-bar app for **Bose QC Ultra Headphones (2nd Gen)**: battery, noise-control modes,
immersive audio, equalizer, shortcut button and Mac output volume, in a Liquid Glass panel.
English, Spanish and Portuguese.

> **Unofficial.** Bossa is not affiliated with, endorsed by or sponsored by Bose Corporation.
> "Bose" is a trademark of its owners and is used here only to say which headphones the app talks to.

## Requirements
- macOS 26 (Liquid Glass), Apple Silicon
- Xcode command-line tools (`swiftc`) and a Rust toolchain
- Bose QC Ultra Headphones (2nd Gen). Pair them once in pairing mode; afterwards they work normally.

## Build
```sh
scripts/build.sh            # build/Bossa.app (ad-hoc signed)
scripts/build.sh --run      # build and launch
scripts/build.sh --install  # install into ~/Applications and launch
cargo test --release        # Rust tests
```
Bluetooth permission is requested on first launch.

## Layout
- `app/`: SwiftUI + AppKit front end
- `core/`: Rust core (BLE session, prefs, volume) exposed to Swift over a C ABI (`core/include/bose_core.h`)
- `crates/`: BMAP protocol and BLE transport
- `i18n/`: `Localizable.strings` per language, generated by `i18n/generate.py`
